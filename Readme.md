# learn drone video list

Add YouTube videos below using this format, then copy each one into the `videos` array in `index.html`.

Thumbnail URL: `https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg`

```js
{
  "title": "Video title",
  "url": "https://www.youtube.com/watch?v=VIDEO_ID",
  "thumbnail": "https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg",
  "category": "General",
  "publishedAt": "2026-09-04",
  "publishedLabel": "Sep 4, 2026"
}
```

Starter categories: **General**, **Playlist**, **Tutorials**. New category names on videos are picked up automatically.
